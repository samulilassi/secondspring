CARD PICTURES
=============
Put one picture per card in this folder. The game finds it by file name and shows it in the arched picture frame at the top of the card.

- Format: .png
- Shape: landscape, about 4:3 (for example 800 x 600 px). The frame is cropped to fill, so keep the important part in the middle; the top corners are rounded off by the arch.
- Name: the card name in lower case, spaces and punctuation replaced with "-" (exactly as listed below).
- A card with no picture just shows the striped placeholder, so you can add them one at a time.
- After adding pictures, reload the game with Ctrl+F5.
- New cards follow the same rule: "My New Card" -> my-new-card.png
